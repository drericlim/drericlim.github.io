This repository holds the new site while it is being built and tested. The live site is still drericlim.com on Squarespace. The domain moves here only once every page is approved and tested.

The test site is published at https://drericlim.github.io/

## Patient guides

Every patient information page uses the layout `_layouts/patient-guide.html`. To add one, copy an existing page folder (for example `your-operation/`), rename it to the page's address, and change the details at the top of `index.html` (between the two `---` lines) and the text below them.

- `title`, `standfirst`, `group` and `group_anchor` (the section of For patients it belongs to: `why`, `techniques`, `screening`, `lung-cancer`, `conditions`) fill the header. `seo_title`, `description` and `address` are for search engines.
- `picture` is a square file in `assets/articles/` (at least 800 by 800, subject in the middle); leave it out and the plain stone shows.
- `brief` is the "In brief" list. `references`, `more_url` with `more_text`, and `related` are optional. In `references`, write Professor Lim's name as `<strong class="me">Lim E</strong>` so it shows bold and underlined, and put each reference in single quotes.
- The text is plain HTML: `<h2 id="…">` for each heading (the "On this page" list is made from these) and `<p>` for paragraphs. For numbered steps, copy the `<ol class="steps">` pattern from `your-operation/index.html`.
- Change `version` and the drafts table or register above with every change.

GitHub Pages builds these pages, so **after every push check that the build succeeded**; a mistake between the `---` lines stops the whole site from updating.

**Drive copies of approved guides: not working yet.** The nightly script (`tools/drive-backup/Code.gs`) expects each page file to contain the robots tag and to be a complete page. A guide's file holds only its details and text; the robots tag and the design are in the layout. So approved guides are **not** added to `tools/drive-backup/pages.json` for now (adding one would make the nightly run report an error). To include them, the script needs a small update (accept a page whose robots tag is in its layout, and save the layout file as well), which Professor Lim then has to paste into his Apps Script project. Until then GitHub's own history is the record of every version of a guide.
