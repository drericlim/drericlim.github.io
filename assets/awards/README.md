# Award photos

Pictures for the Awards list on the About page.

## In this folder

- `laingbuisson-innovation-in-care-2025.jpg`: LaingBuisson Innovation in Care Award, 2025. Professor Lim holding the award on the night, cropped square (400 by 400).
- `iaslc-ginsberg-award.jpg`: IASLC Robert J. Ginsberg Award, 2020. The IASLC logo centred on white (400 by 400).
- `scts-research-prizes.jpg`: Society for Cardiothoracic Surgery research prizes, 2008 to 2011. The SCTS crest centred on white (400 by 400).

Logos sit on a white square with space around them, so the small square on the page never cuts them off.

## Naming

Name of the award and the year, e.g. `laingbuisson-innovation-in-care-2025.jpg`. Square pictures work best, at least 400 by 400 pixels.

Always use lower case, with hyphens instead of spaces, and no other punctuation. To replace a picture, upload a new file **with exactly the same name**: the site picks it up automatically. Keep each file under 500 KB if you can.

If a replaced picture still shows the old version, the browser is showing its saved copy. Ask Claude to add a version date to the picture's address on the page (for example `?v=20261029`).
