# Rotating photos

Three spots on the website rotate through a set of photos, so the site looks fresh:

| Folder | Where it shows |
|---|---|
| `hero/` | The large background photo at the top of the homepage |
| `home-profile/` | The photo in the homepage's About section |
| `about-profile/` | The portrait at the top of the About page |

Upload photos into a folder to add them to that rotation; delete them to remove them. How often each spot changes (weekly or daily) is set in `_data/photo-rotation.yml`. Each folder has a note on the best photos for that spot.
