# virtual Grand Rounds speakers

Headshots of virtual Grand Rounds speakers.

## In this folder

- Empty so far. Until a photo is added, the site shows the speaker's initials.

## Naming

The speaker's name, e.g. `jane-smith.jpg`. Square headshots, at least 400 by 400 pixels (shown in a circle).

Always use lower case, with hyphens instead of spaces, and no other punctuation. To replace a picture, upload a new file **with exactly the same name**: the site picks it up automatically. Keep each file under 500 KB if you can.
