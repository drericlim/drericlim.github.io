# Partner and sponsor logos

Logos for the partner band on the virtual Grand Rounds page.

## In this folder

- `medtronic.svg`, `astrazeneca.svg`: stand-ins copied from a public logo website for the mock-up. Replace with the official files from each company.
- Still needed: `medela.svg` (the page still borrows the Medela logo from a public logo website).

## Naming

The organisation's name, e.g. `medtronic.svg`. The SVG format is best, PNG with a transparent background is fine. Use the official logo each partner supplies.

Always use lower case, with hyphens instead of spaces, and no other punctuation. To replace a picture, upload a new file **with exactly the same name**: the site picks it up automatically. Keep each file under 500 KB if you can.
