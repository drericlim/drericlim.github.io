# General photos

Photos of Professor Lim and of the hospital, used across the site.

## In this folder

- `eric-lim-portrait.jpg`: main portrait. It's the picture shown when any page is shared on social media and the one Google is told about. (The homepage and About page photos now rotate; see `assets/rotating/`.)
- `eric-lim-portrait-2.jpg`: second portrait (also in the rotating sets).
- `ward-round.jpg`: Professor Lim on a ward round, for the Testimonials page.

## Naming

Describe what is in the photo, e.g. `royal-brompton-entrance.jpg`. Landscape photos for page backgrounds should be at least 2000 pixels wide.

Always use lower case, with hyphens instead of spaces, and no other punctuation. To replace a picture, upload a new file **with exactly the same name**: the site picks it up automatically. Keep each file under 500 KB if you can.
