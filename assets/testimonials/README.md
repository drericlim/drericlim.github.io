# Patient photos

Photos patients have sent with their testimonials. Only add a photo when the patient has agreed in writing to it being published.

## In this folder

- `duilio-barbosa.jpg`, `richard-warren.jpg`, `erika-dwek.jpg`, `tony-marsh.jpg` (to check: it shows a woman and a baby).

## Naming

The patient's name, e.g. `jane-smith.jpg`, at least 800 pixels wide. Put the same file name on the `photo:` line of their entry in `_data/testimonials.yml`.

Always use lower case, with hyphens instead of spaces, and no other punctuation. To replace a picture, upload a new file **with exactly the same name**: the site picks it up automatically. Keep each file under 500 KB if you can.
