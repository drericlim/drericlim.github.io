# Film covers

The picture shown behind the play button for each film on the About page, before a visitor presses play.

## In this folder

- `vimeo-199325659.jpg`: Introduction 1
- `vimeo-199445739.jpg`: Introduction 2
- `vimeo-231725351.jpg`: ctDNA research

These were taken from each film's Vimeo thumbnail, with the black cinema bars trimmed off.

## Naming

`vimeo-` followed by the film's Vimeo number, e.g. `vimeo-231725351.jpg`. Put the same file name on the `thumbnail:` line of the film in `_data/about-films.yml`. Landscape (16:9), at least 1280 pixels wide, under 500 KB. If no cover is given, the play button sits on a plain dark background.
